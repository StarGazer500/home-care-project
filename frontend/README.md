# Caring Hearts Healthcare - Alternative Design

A warm, organic healthcare services website with earthy tones and a magazine-editorial aesthetic.

## Design Philosophy

This alternative design takes a completely different approach from the modern/tech version:

### Visual Style
- **Warm Color Palette**: Terracotta (#D8725F), Sage (#8FA882), Sand (#F5EFE6)
- **Organic Shapes**: Rounded corners, soft shadows, natural feel
- **Editorial Typography**: Cormorant Garamond (serif display) + Work Sans (clean body)
- **Calming Aesthetic**: Less tech-focused, more human-centered

### Key Differences from Design 1

**Design 1 (Modern Tech)**:
- Blue/Purple gradients
- Glass morphism effects
- Sharp, modern feel
- Playfair Display + Plus Jakarta Sans

**Design 2 (Warm Organic)**:
- Terracotta/Earth tones
- Solid colors with soft borders
- Warm, welcoming feel  
- Cormorant Garamond + Work Sans

## Features
